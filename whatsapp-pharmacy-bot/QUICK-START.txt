📍 CURRENT LOCATION:
   /workspaces/yellowapps/whatsapp-pharmacy-bot

🚀 START THE BOT (3 OPTIONS):

   Option 1: Auto-start script (EASIEST)
   ────────────────────────────────────
   $ ./start.sh

   Option 2: Manual start
   ────────────────────────────────────
   $ cp .env.example .env
   $ nano .env                    # Add your OpenAI API key
   $ npm install
   $ npm start

   Option 3: Without OpenAI
   ────────────────────────────────────
   $ npm install
   $ npm start                    # Uses fallback responses

📱 OPEN IN BROWSER:
   http://localhost:3000

📞 NEED HELP?
   Check the logs in the terminal where you ran 'npm start'

🔧 TROUBLESHOOTING:
   Problem: "OpenAI not configured"
   Solution: Add OPENAI_API_KEY to .env file

   Problem: "Cannot find module"
   Solution: Run 'npm install'

   Problem: Port 3000 in use
   Solution: Change PORT in .env to 3001
